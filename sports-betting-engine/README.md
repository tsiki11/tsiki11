# ⚽ betengine — Μηχανή στατιστικών & value betting ποδοσφαίρου (v0.1)

Υπολογίζει στατιστικά ομάδων, εκτιμά πιθανότητες για μελλοντικούς αγώνες με μοντέλο
**Dixon-Coles** και τις συγκρίνει με τις αποδόσεις των bookmakers για να βρει πιθανά **value bets**.
Περιλαμβάνει **walk-forward backtest**, ώστε να ελέγχεις αν η στρατηγική θα είχε βγάλει κέρδος στο παρελθόν.

> ⚠️ Το backtest της v0.1 **δεν αποδεικνύει edge** απέναντι στην αγορά (βλ. [Αποτελέσματα](#αποτελέσματα-backtest)).
> Χρησιμοποίησέ το ως εργαλείο ανάλυσης και ως βάση για βελτιώσεις, όχι ως σύστημα πονταρίσματος.

## Λίγκες & δεδομένα
Πηγή: [football-data.co.uk](https://www.football-data.co.uk). Δωρεάν CSV με αποτελέσματα, σουτ, κόρνερ, κάρτες
και αποδόσεις (pre-match και closing).

## Εγκατάσταση & χρήση
```bash
cd sports-betting-engine
pip install -r requirements.txt

python -m betengine download                      # 6 σεζόν ιστορικού + fixtures
python -m betengine stats --leagues G1            # βαθμολογία, σουτ, φόρμα, ratings -> Excel
python -m betengine backtest                      # walk-forward backtest -> reports/backtest.xlsx
python -m betengine predict --bankroll 1000       # προβλέψεις & value bets για επερχόμενους αγώνες
python -m betengine season-test --train 2324 2425 --test 2526   # εκμάθηση σε 2 σεζόν, έλεγχος σε τρίτη
```
Χρήσιμες επιλογές: `--leagues G1 E0`, `--min-edge 0.05`, `--market-weight 0.6`, `--markets 1X2 OU25`,
`--kelly 0.25`, `--max-stake 0.02`, `--test-from 2025-07-01`. Τρέξε `python -m betengine <εντολή> -h` για όλες.

Το `predict` χρησιμοποιεί το `fixtures.csv` του football-data, που ενημερώνεται συνήθως λίγες μέρες πριν από κάθε
αγωνιστική. Σε διακοπή για τις εθνικές ομάδες δεν θα βρει αγώνες.

## Πώς δουλεύει

```
CSV ─► data.py ─► model.py (Dixon-Coles) ─► πιθανότητες ─► blending με αγορά ─► value bets ─► Excel
                     ▲                                                              │
                     └──────────── backtest.py (walk-forward, χωρίς look-ahead) ◄───┘
```

**1. Μοντέλο γκολ (`model.py`).** Τα γκολ κάθε ομάδας ακολουθούν κατανομή Poisson:

```
λ_γηπεδούχου = exp(μ0 + home + att[γηπεδούχος] + def[φιλοξενούμενος])
μ_φιλοξ.     = exp(μ0 +        att[φιλοξενούμενος] + def[γηπεδούχος])
```
- `ρ` διορθώνει τα σκορ 0-0, 1-0, 0-1 και 1-1.
- Το time decay `exp(-0.0018 × ημέρες)` δίνει μεγαλύτερο βάρος στους πρόσφατους αγώνες (half-life ~1 έτος).
- Το ridge penalty τραβάει ομάδες με λίγα δεδομένα (π.χ. νεοφώτιστες) προς τον μέσο όρο.

Από τα λ και μ φτιάχνεται ο πίνακας πιθανοτήτων για κάθε σκορ, και από αυτόν οι πιθανότητες για **1X2, Over/Under 2.5, BTTS**
και το πιο πιθανό σκορ.

**2. Αγορά (`markets.py`).** Απόδοση 2.00 σημαίνει implied πιθανότητα 50%. Επειδή το άθροισμα των implied πιθανοτήτων
είναι >100% λόγω του margin του bookmaker, τις κανονικοποιούμε (devig).

**3. Blending.** `p = 0.4 × μοντέλο + 0.6 × αγορά`. Το μοντέλο ξέρει μόνο γκολ, ενώ η αγορά ξέρει επιπλέον για
τραυματισμούς, ενδεκάδες και κίνητρα. Με blending ποντάρουμε μόνο όταν το μοντέλο διαφωνεί *έντονα*.

**4. Value & stake.** `EV = p × απόδοση − 1`. Στοίχημα γίνεται όταν EV ≥ 5% και η απόδοση είναι ≤ 5.0.
Το stake βγαίνει από **¼ Kelly** `(p·o − 1)/(o − 1)`, με ανώτατο όριο 2% του bankroll.

**Παράδειγμα:** μοντέλο Over 2.5 = 58%, αγορά (χωρίς margin) = 50% → p = 0.4·0.58 + 0.6·0.50 = **53.2%**.
Με απόδοση 2.05: EV = 0.532 × 2.05 − 1 = **+9.1%**. Kelly = 0.091 / 1.05 = 8.7%, ¼ Kelly = 2.2% → cap **2%**,
δηλαδή 20€ σε bankroll 1000€.

## Αποτελέσματα backtest
Walk-forward: κάθε εβδομάδα το μοντέλο εκπαιδεύεται μόνο με αγώνες που έχουν ήδη παιχτεί. Οι αποδόσεις στοιχήματος
είναι ο μέσος όρος της αγοράς (`Avg`) και το σημείο αναφοράς είναι οι closing odds (Pinnacle).
**Tuning:** σεζόν 2024-25. **Holdout:** 2025-26 και τρέχουσα σεζόν (έως 11/2026), όλες οι 6 λίγκες.

| Ρύθμιση | Περίοδος | Στοιχήματα | ROI | SE (τυπικό σφάλμα) | CLV |
|---|---|---|---|---|---|
| Μόνο μοντέλο, 1X2 + O/U | 2024-07 → σήμερα | 3,687 | **−9.9%** | 2.1% | −2.2% |
| Blending 0.6, 1X2 + O/U | holdout | 330 | −13.6% | 7.7% | −1.3% |
| **Blending 0.6, μόνο O/U 2.5 (προεπιλογή)** | holdout | 112 | +3.4% | 11.3% | −0.3% |

Log-loss 1X2 στο holdout (χαμηλότερο = καλύτερο): μοντέλο μόνο του 0.981, μοντέλο με blending 0.969,
pre-match αγορά 0.965, closing αγορά 0.962.

**Ερμηνεία:**
- Το μοντέλο είναι **καλά calibrated**: όταν λέει 45%, το αποτέλεσμα βγαίνει περίπου 45% των φορών. Είναι όμως **λιγότερο
  ακριβές από την αγορά**.
- Μόνο του χάνει καθαρά. Με blending και μόνο O/U φτάνει περίπου στο **νεκρό σημείο**. Το +3.4% είναι μέσα στο ±2 SE
  (δηλαδή ±22%), άρα **δεν ξεχωρίζει από την τύχη**.
- Το **CLV ≤ 0** σημαίνει ότι η αγορά δεν κινείται υπέρ των επιλογών μας. Αυτός είναι ο πιο αξιόπιστος δείκτης ότι
  δεν υπάρχει (ακόμα) πραγματικό edge.

## Τεστ σεζόν: εκμάθηση 2023-25, προβλέψεις 2025-26
Έτρεξαν δύο εκδοχές: **A. frozen**, όπου το μοντέλο μαθαίνει μία φορά και δεν ενημερώνεται, και **B. walk-forward**,
όπου μαθαίνει κάθε εβδομάδα τους αγώνες που έχουν ήδη παιχτεί. Το τεστ κάλυψε 6 λίγκες και ~1,990 αγώνες.

| | A. frozen | B. walk-forward | Αγορά |
|---|---|---|---|
| Σωστό 1/X/2 (πιο πιθανό αποτέλεσμα) | 50.9% | 51.8% | 53.1% (φαβορί) |
| Σωστό Over/Under 2.5 | 54.0% | 56.4% | 57.4% |
| Log-loss 1X2 | 1.009 | 0.990 | 0.975 |

- Οποιοδήποτε βάρος δοθεί στο μοντέλο πάνω στις πιθανότητες της αγοράς **χειροτερεύει** το log-loss, ακόμα και 10%.
  Άρα το μοντέλο δεν προσθέτει πληροφορία που να μην έχει ήδη η αγορά.
- Τα value bets έχουν **αρνητικό CLV σε όλα τα σενάρια**. Τα θετικά ROI (+2% έως +14%) αφορούν 80-180 στοιχήματα,
  με SE 8-13%, και δεν ξεχωρίζουν από την τύχη.
- Στους αγώνες νεοφώτιστων ομάδων το μοντέλο υστερεί περισσότερο: 45.8% σωστά έναντι 51.7% της αγοράς.

## Επόμενα βήματα (v0.2+), κατά σειρά προτεραιότητας
1. **Shots-based ratings:** χρήση σουτ εντός εστίας ή xG στη θέση των γκολ. Είναι λιγότερο θορυβώδη και αποτελούν
   την πιο πιθανή πηγή πληροφορίας που η αγορά υποτιμά.
2. **Line shopping:** ποντάρισμα στην καλύτερη διαθέσιμη απόδοση (`Max`) αντί για τον μέσο όρο (`Avg`).
3. **Ξεχωριστές ρυθμίσεις ανά λίγκα** (ξ, blending). Θέλει προσοχή γιατί αυξάνει τον κίνδυνο overfitting.
4. **Paper trading:** καταγραφή των προβλέψεων πριν από τους αγώνες για 2-3 μήνες και παρακολούθηση του CLV.

> Υπεύθυνος τζόγος: οι πιθανότητες δεν είναι βεβαιότητες, και ακόμα και ένα μοντέλο με θετικό edge περνάει
> μεγάλα drawdowns. Στο backtest, ακόμη και η συντηρητική ρύθμιση είχε drawdown ~13% του bankroll.
